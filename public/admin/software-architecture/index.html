Site Identity

Feature Toggles

JSON-LD Structured Data Injects Person + ProfilePage + TechArticle schema. Enables AI engines (Google SGE, Perplexity, Bing Copilot) to cite you as the answer source.
Sitemap Serves /sitemap.xml with all published articles. Allows Google to discover every article automatically without relying on crawl luck.
French hreflang (fr) Adds hreflang="fr" links so Google indexes French and English versions as separate search results. Only enable when French article content is ready.
Block all indexing (noindex) Adds noindex, nofollow to every page. Use only during maintenance. Removes the site from Google within days — hard to recover from.

AI Search Engines (GEO)

Generative Engine Optimisation — control how ChatGPT, Perplexity, Google SGE, Claude and Bing Copilot discover, crawl, and cite your content. These settings are the fastest-growing discovery channel in 2025–26.

LLMs.txt Serves /llms.txt — the emerging standard (like robots.txt for AI crawlers) that tells ChatGPT, Claude, and Perplexity what content to index and summarise. Increases citation probability in AI-generated answers.
Allow AI Crawlers (GPTBot, ClaudeBot, PerplexityBot) When enabled, robots.txt explicitly allows GPTBot, ClaudeBot, PerplexityBot, and anthropic-ai. Disabling blocks them, which prevents AI engines from using your content in answers.
E-E-A-T Author Signals Adds citation_author, citation_title, and citation_publication_date meta tags to every article page. These are the signals Google SGE, Perplexity, and ChatGPT use to attribute authorship and boost credibility (Experience, Expertise, Authoritativeness, Trustworthiness).

Atlas AI

AI Configuration

Tune every layer of the Atlas AI pipeline — models, embeddings, chunking, retrieval, prompts, routing, evaluation thresholds, observability, cost controls, and security.

psychology 1. LLM Configuration

Models available to visitors, generation parameters, and streaming behaviour. Changes take effect on the next chat session.

Streaming Stream tokens progressively. Disable for simpler single-shot responses.
Show model picker in chat Let visitors switch between Fast & More detailed.
hub 2. Embedding Configuration

Controls the model and parameters used when converting article chunks and user queries into vectors. Re-index articles after changing these.

splitscreen 3. Chunking Strategy

How articles are split into chunks before embedding. Smaller chunks = more precise retrieval. Larger = more context per chunk. Re-run the backfill after changing.

Splitter Type
manage_search 4. Retrieval Configuration

Controls how the vector store is queried at chat time. RAG must be enabled and articles indexed before these take effect.

Enable RAG for Atlas Retrieve article chunks at query time. Keep off until the knowledge base is indexed.
Hybrid Search Combine vector search with keyword BM25 scoring for better recall on rare terms.
Reranker Run a cross-encoder over the top-K results to reorder by relevance before injecting into the prompt.
auto_awesome 5. Prompt Configuration

Override the default Atlas persona prompt and configure guardrails. Leave blank to use the built-in persona.

This replaces the built-in persona when non-empty. RAG context is still injected above it when RAG is enabled.

Guardrails Reject off-topic or adversarial inputs before they reach the LLM.
alt_route 6. Model Routing

Route different query types to different models to optimise cost vs quality. Default sends all queries to the selected default model.

Used when the primary model is unavailable or rate-limited.

rule 7. Evaluation Configuration

Thresholds used by the AI Evaluation page to determine PASS / FAIL. Adjust as your knowledge base matures.

Current defaults: Recall ≥ 80%, MRR ≥ 0.70. These values are read by the evaluation runner at the start of each run.

visibility 8. Observability Configuration

Control what is captured per request. Enabling prompt/chunk capture increases Firestore storage. Tokens are always counted for billing.

Enable TracingWrite a trace document per request with latency breakdown.
Capture PromptsStore the full system + user prompt per request.
Capture Retrieved ChunksStore the top-K chunk IDs and scores per RAG request.
Capture TokensCount input/output tokens and estimated cost per request. Recommended on.
payments 9. Cost Controls

Atlas stops accepting new questions once a budget cap is hit. Set to 0 to disable that cap. Token limit prevents a single malicious query from consuming disproportionate quota.

security 10. Security

Protect the pipeline from abuse. Rate limiting applies per authenticated user. Content moderation uses Gemini's safety filters.

PII RedactionStrip personally identifiable information from user messages before sending to the LLM.
Prompt Injection DetectionDetect and block attempts to override the system prompt via user messages.
Content ModerationApply Gemini safety filters before returning responses to visitors.
